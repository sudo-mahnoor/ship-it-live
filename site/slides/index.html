Quick quiz

Spot the leaked secret 🔑

A

const port = 3000;
const appName = "Codrithm";
const debug = false;

B

const db = "postgres";
const apiKey =
  "sk_live_51HxDEMOKEY";
const retries = 3;

C

const apiKey =
  process.env.API_KEY;
const region = "ap-south-1";

B leaks a live key. Bots scan GitHub for keys all day.
C is the right way: secrets live in environment variables and GitHub Secrets, never in code.
